# FLIPER - Gaming 4 gamers

Site de e-commerce de eletrônicos gamer (páginas **index** e **login**), desenvolvido a partir do protótipo criado no Figma.

## Tecnologias
- HTML5 e CSS3 (com media queries)
- Bootstrap 5.2.2 (grid, navbar responsiva, toast)
- JavaScript e jQuery 3.6.1

## Estrutura
```
index.html        página inicial (menu, banner, produtos, rodapé)
login.html        login e cadastro
css/estilo.css    estilos do projeto
js/script.js      carrinho, voltar ao topo, login e cadastro
js/jquery-script.js  alterna entre login e cadastro
img/              imagens usadas no protótipo
```

## Como testar
Abra o `index.html` no navegador (é preciso internet para carregar Bootstrap, jQuery e as fontes).
